## Задача 1: Разстояние върху числовата права
Въвеждат се две реални числа `a` и `b`, които са точки върху числовата права. Изведете разстоянието между тях с точност до 2 знака след десетичната запетая.

**Формула:**

$$d = |a - b|$$

| Функция | Действие |
|---|---|
| `fabs(x)` | абсолютна стойност на реално число |
| `abs(x)` | абсолютна стойност на цяло число (от `stdlib.h`) |

**Вход:**
```
-3.5 2
```
**Изход:**
```
5.50
```

## Задача 2: Разстояние между две точки
Въвеждат се координатите на две точки `A(x1, y1)` и `B(x2, y2)`. Изведете разстоянието между тях с точност до 2 знака след десетичната запетая.

**Формула:**

$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

| Функция | Действие |
|---|---|
| `sqrt(x)` | корен квадратен от `x` |
| `pow(x, n)` | `x` на степен `n` |

**Вход:**
```
1 2
4 6
```
**Изход:**
```
5.00
```

## Задача 3: Точка в кръг
Въвеждат се център `(cx, cy)` и радиус `r` на окръжност, след това точка `(x, y)`. Изведете `1`, ако точката е вътре в кръга или върху окръжността, и `0` в противен случай.

**Формула:** точката е в кръга, когато разстоянието до центъра не надвишава радиуса:

$$\sqrt{(x - c_x)^2 + (y - c_y)^2} \le r$$

**Вход:**
```
1 1 3
3 2
```
**Изход:**
```
1
```

**Вход:**
```
0 0 2
2 2
```
**Изход:**
```
0
```

## Задача 4: Точка в квадрат
Въвеждат се център `(cx, cy)` и дължина на страната `a` на квадрат със страни, успоредни на осите, след това точка `(x, y)`. Изведете `1`, ако точката е вътре в квадрата или върху страните му, и `0` в противен случай.

**Формула:**

$$|x - c_x| \le \frac{a}{2} \quad \text{и} \quad |y - c_y| \le \frac{a}{2}$$

**Вход:**
```
0 0 4
1.5 -2
```
**Изход:**
```
1
```

**Вход:**
```
0 0 4
3 1
```
**Изход:**
```
0
```

## Задача 5: Точка в ромб
Въвеждат се център `(cx, cy)` и половината от диагонала `d` на ромб (квадрат, завъртян на 45°), с върхове `(cx ± d, cy)` и `(cx, cy ± d)`. След това се въвежда точка `(x, y)`. Изведете `1`, ако точката е вътре в ромба или върху страните му, и `0` в противен случай.

**Формула:**

$$|x - c_x| + |y - c_y| \le d$$

**Вход:**
```
0 0 3
1 2
```
**Изход:**
```
1
```

**Вход:**
```
0 0 3
2 2
```
**Изход:**
```
0
```

## Задача 6: Оцветена област
Напишете логически израз, който се оценява като истина, ако точка с координати `(x, y)` принадлежи на оцветената област, и като лъжа в противен случай.

Оцветената област се състои от две части:
1. **Горната половина** (`y ≥ 0`) на кръг с център `(0, 0)` и радиус `4`, **без** ромба с център `(0, 0)` и половин диагонал `2`.
2. Квадратът с върхове `(0, 0)`, `(4, 0)`, `(4, -4)` и `(0, -4)`.

Границите принадлежат на областта.

Въвежда се точка `(x, y)`. Изведете `1` или `0`.

| Вход | Изход |
|---|---|
| `0 3` | `1` |
| `0 1` | `0` |
| `2 -2` | `1` |
| `-2 -2` | `0` |
| `3 3` | `0` |
